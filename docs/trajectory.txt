1. 运行时模块关系图
-------------------

下面是从传感器到轨迹输出的主链路：

    ┌─────────────────────────────────────────────────────────────┐
    │                         Sensors                             │
    ├───────────────────────┬───────────────────┬─────────────────┤
    │ LiDAR point cloud      │ IMU               │ RTK/GNSS Fix     │
    │ /points_raw or /lidar  │ /imu or /imu/data │ /fix or /navSatFix│
    └───────────┬───────────┴─────────┬─────────┴────────┬────────┘
                │                     │                  │
                v                     v                  v
        ┌──────────────────────────────────┐      ┌──────────────────────┐
        │ FAST-LIO2 / spark_fast_lio       │      │ RTK preprocessing     │
        │ spark_lio_mapping or lio_node    │      │ rtk_fusion/*.cpp      │
        ├──────────────────────────────────┤      ├──────────────────────┤
        │ 点云去畸变                       │      │ NavSatFix 质量门控     │
        │ IMU 预积分/状态预测              │      │ WGS84 -> ENU           │
        │ scan-to-map 匹配                 │      │ GNSS-LiDAR 外参转换    │
        │ 输出局部 LiDAR-IMU 里程计         │      │ RTK 跳变检测           │
        └────────────────┬─────────────────┘      │ Fixed/Float 噪声建模  │
                         │                        └──────────┬───────────┘
                         │                                   │
                         v                                   v
        ┌───────────────────────────────────────────────────────────────┐
        │ Factor Graph / SAM / PGO                                      │
        ├───────────────────────────────────────────────────────────────┤
        │ 里程计约束：来自 LiDAR-IMU 前端                               │
        │ 回环约束：ICP 子图匹配 / simple_pgo                           │
        │ RTK 约束：GTSAM GPSFactor，噪声由 Fixed/Float 和协方差决定     │
        │ 增量优化：更新关键帧位姿和全局一致轨迹                        │
        └───────────────────────────────┬───────────────────────────────┘
                                        │

        ┌───────────────────────────────────────────────────────────────┐

2. 因子图约束结构
-----------------

核心图优化可以理解为：

    X0 ---- odom ---- X1 ---- odom ---- X2 ---- odom ---- X3 ---- ...
     │                │                 │                 │
     │                │                 │                 │
   RTK              RTK               RTK               RTK
   GPSFactor        GPSFactor         GPSFactor         GPSFactor
     │                                  ▲
     │                                  │
     └──────────── loop closure ────────┘
